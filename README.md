# 🏥 Sistema de Agendamento de Consultas

Projeto desenvolvido como atividade do curso técnico de Desenvolvimento de Sistemas, com o objetivo de criar uma API REST para gerenciamento de pacientes e consultas em uma clínica.

# 📌 Sobre o Projeto

Este sistema foi criado para facilitar o controle de atendimentos em clínicas e consultórios, permitindo organizar informações de pacientes e consultas de forma prática e eficiente.

A aplicação resolve problemas como:

Conflitos de horários
Falta de organização nos agendamentos
Dificuldade em gerenciar pacientes

Tudo isso utilizando uma API REST, sem interface gráfica, com testes feitos via ferramentas como Postman ou Thunder Client.

# 🚀 Tecnologias Utilizadas
Java ☕
Spring Boot 🌱
MySQL 🗄️
Maven 📦
Postman / Thunder Client (para testes)
